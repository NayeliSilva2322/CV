# Foto de perfil

Coloca aquí tu fotografía **con el fondo eliminado** (PNG con
transparencia) con el nombre exacto:

```
photo.png
```

El componente `Hero.jsx` ya apunta a `/profile/photo.png`. Mientras no
agregues el archivo, el hero se ve igual de bien: muestra solo el efecto
de resplandor (glow) sin foto rota.

Recomendaciones:
- Usa un fondo transparente (PNG) para que se integre con el fondo oscuro.
- Resolución sugerida: al menos 800x1000px, recorte de medio cuerpo o
  retrato.
