# Carpeta del CV

Coloca aquí tus dos versiones del CV en PDF, con estos nombres exactos:

```
CV_Cyndi_Silva_Abanto.pdf       <- versión en español (botón "Descargar CV" en ES)
CV_Cyndi_Silva_Abanto_EN.pdf    <- versión en inglés  (botón "Download CV" en EN)
```

El sitio detecta automáticamente el idioma activo y apunta al PDF
correspondiente (ver `cvPath` en `src/i18n/content.es.js` y
`src/i18n/content.en.js`). Si usas otros nombres de archivo, actualiza esa
propiedad en ambos archivos.
